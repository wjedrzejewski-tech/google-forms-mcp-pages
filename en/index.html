ChatGPT Google Forms MCP

A limited-access test integration designed to operate Google Forms through a single Google account used for RCIiTT ZUT purposes.

Current status: synthetic-data testing only. The MCP server allows only the rciittzut@gmail.com account. This is not a public service for general Google users.

What can this integration do?

  • Create unpublished Google Forms.
  • Read form structure and add or edit questions only in unpublished forms that have never received responses.
  • Read form responses available to the connected Google account when explicitly requested by the authorized user.
  • Check the connection status with Google.

How does access work?

The user authorizes a Google account through OAuth. The remote MCP server runs on Cloudflare Workers and communicates with the Google Forms API. Access to tools requires authentication in ChatGPT and an allowed Google account. The app does not expose question deletion or form publishing tools.

Scope of use

This solution is used for the RCIiTT ZUT account, which is not part of Google Workspace. This page exists only to describe the technical integration and is not an official university information service. Processing real respondent data or organizational data requires separate review and authorization.

Contact and privacy

Contact for this integration: rciittzut@gmail.com. Data-handling and access-revocation rules are described in the privacy policy.
